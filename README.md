## 🧠 Áreas de interés

- **Arquitectura de software:** patrones de diseño, modularidad, separación de responsabilidades y sistemas escalables.
- **Algoritmos y estructuras de datos:** geometría computacional, métodos numéricos y resolución de problemas.
- **Ingeniería backend:** desarrollo de APIs, optimización de consultas, caché y procesamiento asíncrono.
- **Sistemas distribuidos:** mensajería, consistencia eventual, concurrencia y arquitecturas orientadas a eventos.
- **Programación de sistemas:** rendimiento, administración de memoria y desarrollo de librerías.
